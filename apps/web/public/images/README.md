# Assets de Stitch

Imágenes de referencia descargadas de los enlaces de Google contenidos en los dos exports
`stitch_streaming_responsive_web_ui_system*.zip`.
Se conservan los JPEG originales; no son material generado nuevo ni imágenes de usuarios reales.

- `explore-N.jpg`: imágenes en orden de aparición de `03_explorar_y_buscar/code.html`.
- `studio-N.jpg`: monitor y portada de `07_08_estudio_prototipo_interactivo/code.html`.

Solo se versionan imágenes utilizadas. El prefijo y número permiten rastrear el enlace original
sin incorporar HTML exportado, scripts remotos o credenciales. Assets importados con `@/public/images/`
se incluyen en el build con nombres hash. Las fuentes Inter y Plus Jakarta Sans se empaquetan desde
los paquetes @fontsource-variable y conservan sus licencias en sus dependencias.
