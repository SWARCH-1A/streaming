# Marca Vault tv

`vault-tv.png` es el logo proporcionado por el equipo para la identidad de la Web.
Usamos el archivo original y ajustamos su encuadre con CSS en el componente Brand.
El enlace tiene el nombre accesible «Vault tv, inicio». Su imagen se marca como decorativa
para que el lector de pantalla no anuncie el nombre dos veces. El logo se sirve localmente.
