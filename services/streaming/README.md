# Core / Emisiones

Emisiones es un módulo interno de Core, con interfaces locales, PostgreSQL y el stack de Core.
La definición es [SPEC-04](../../docs/spec-p1/spec_04_stream.md) y el
[mapa de responsabilidades](../../docs/mapa_sdd_p1.md). Su implementación pertenece a services/core;
esta carpeta contiene documentación, sin build de servicio propio.
