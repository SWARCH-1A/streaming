# Core / Canales

Canales es un módulo interno de Core, con interfaces locales, PostgreSQL y el stack de Core.
La definición es [SPEC-03](../../docs/spec-p1/spec_03_channel.md) y el
[mapa de responsabilidades](../../docs/mapa_sdd_p1.md). Su implementación pertenece a services/core;
esta carpeta contiene documentación, sin build de servicio propio.
